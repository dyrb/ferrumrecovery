# Changelog

## 0.1.0-beta.1

First public preview for Windows 10 and 11, x64.

- Native Win32 interface and command-line tools for NTFS, FAT12/16/32 and exFAT.
- Quick metadata scans, free-space search and full-range search including allocated space.
- Historical filesystem reconstruction, detached NTFS records and signature-based recovery.
- Folder tree, filters, file selection, image/text/hex previews and CSV export.
- Saved scans and resumable source imaging.
- Portable settings, English and Russian, system light and dark themes.

Recovery states are estimates. Signature matches and text fragments are candidates,
not proof of complete recoverable files. See the README for supported sources and limits.
